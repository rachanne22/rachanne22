# rachanne22

Minimal Vite site for local development and Cloud Agent environment verification.

## Development

```bash
npm ci
npm run dev
```

Open http://127.0.0.1:5173 and use **Log a visit** to confirm the app persists state in `localStorage`.

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Vite dev server on port 5173 |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |
